# ⚡ Personal AI Assistant — Web Edition

### Trợ lý cá nhân trực tuyến · Tự nhiên · Gọn nhẹ

Dự án xây dựng một trợ lý AI chạy trên trình duyệt, hỗ trợ trò chuyện tự nhiên và các tác vụ hằng ngày. Ứng dụng sử dụng Google Gemini API để xử lý yêu cầu AI.

## ✨ Tính năng

- 🗣️ Trò chuyện tự nhiên, gần gũi.
- ⚡ Kết nối mô hình AI thông qua Gemini API.
- 💻 Giao diện web sử dụng HTML, CSS và JavaScript.
- 🚀 Có thể triển khai thành website công khai bằng GitHub Pages.
- 🔐 Hỗ trợ người dùng nhập API key trên giao diện.

## 🌐 Demo trực tuyến

Website chưa có đường dẫn công khai được xác nhận.

Đường dẫn `[SWAP](https://thanhdanh-a.github.io/D-n-b-m-t-quoc-gia-Ss1/)` chỉ hoạt động trên máy tính cá nhân, không thể dùng làm link demo công khai.

### Cách triển khai website

1. Đổi tên file `index.html.html` thành `index.html`.
2. Tải file `index.html` lên thư mục gốc của repository.
3. Mở **Settings → Pages** trên GitHub.
4. Chọn **Deploy from a branch**, nhánh `main`, thư mục `/(root)`.
5. Nhấn **Save** và đợi GitHub Pages hoàn tất triển khai.

Link dự kiến:

`https://thanhdanh-a.github.io/D-n-b-m-t-qu-c-gia-Ss1/`

Chỉ chia sẻ link sau khi triển khai thành công và kiểm tra trang web mở được.

## 🚀 Hướng dẫn sử dụng

1. Mở website sau khi triển khai.
2. Nếu ứng dụng yêu cầu API key, truy cập [Google AI Studio](https://aistudio.google.com/) để tìm hiểu cách tạo key.
3. Nhập key vào giao diện theo hướng dẫn của ứng dụng.
4. Gửi tin nhắn để thử nghiệm chức năng trợ lý AI.

**Lưu ý chi phí:** Mã nguồn có thể sử dụng miễn phí. Việc gọi Gemini API phụ thuộc vào hạn mức và chính sách giá hiện hành của Google.

**Lưu ý bảo mật:** Không đưa API key vào mã nguồn công khai. Nếu lưu key trong `localStorage`, key có thể bị người có quyền truy cập trình duyệt xem được.
